# Disaggregated Request Lifecycle Figures

The SVG files are the canonical, editable sources and the assets embedded by
the in-repo design. Their titles, descriptions, and adjacent text equivalents
provide the accessible workflow descriptions.

The matching PNG files are raster derivatives for embedding surfaces such as
Google Docs that do not reliably accept SVG. Regenerate each PNG at the SVG's
intrinsic width and height after every SVG change; do not edit the PNG directly.
